# Contributing to MUX Releases

This is a **distribution-only repository**. MUX's application source code is not maintained in this public Git history. Pull requests adding unrelated application source, build outputs, unsigned XPI files, cookies, browser profiles or private review evidence will not be accepted.

Useful public contributions include corrections to the installation documentation, reporting broken download links, accessibility feedback and reproducible non-sensitive compatibility reports.

Please check existing public documentation and issues before opening a new one. Provide an operating system, Firefox version and exact release tag where applicable. Use only synthetic/disposable accounts and test profiles when sharing reproduction steps.

**Do not open a public issue for suspected security vulnerabilities**, and never attach login details, recovery codes, TOTP seeds, cookies, account backups or private logs. See [SECURITY.md](SECURITY.md) instead.

Only the project's approved release workflows may add or change signed release assets and the production `gh-pages/updates.json` feed. Public pull requests are not a release approval mechanism.
